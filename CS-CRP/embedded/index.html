Smart Room Monitor and Bus Collision Solver

Technology Used: I2C (Inter-Integrated Circuit)

Parts List

  • ESP32 DevKit v4
  • SSD1306 OLED Display (0x3C)
  • MPU6050 Accelerometer / Gyroscope (configured at 0x69 via ADO to avoid 0x68 conflict)
  • DS1307 Real-Time Clock Module (0x68)
  • I2C LCD1602 Display (0x27)

How It Works & Pushing I2C to Its Full Extent

This project uses only the I2C bus to coordinate multiple peripherals on shared SDA and SCL lines while preventing address collisions. On startup, the ESP32 scans the I2C bus and separates the MPU6050 from the DS1307 RTC address clash (0x68) by addressing the MPU6050 at 0x69, then continuously plots live pitch/roll tilt data on the SSD1306 OLED alongside real-time clock updates on the LCD1602.
